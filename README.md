# AiBoost Pro — aiboostpro.lv

AI risinājumu un digitālā mārketinga aģentūras mājaslapa. Statiska vietne, kas tiek publicēta caur GitHub Pages.

**Dzīvā versija:** https://aiboostpro.lv

## Saturs

| Fails | Apraksts |
|---|---|
| `index.html` | Galvenā lapa (LV) — pakalpojumi, cenas, LIAA sadaļa, FAQ, kontaktforma |
| `privacy.html` | Privātuma politika |
| `terms.html` | Lietošanas noteikumi |
| `404.html` | Kļūdas lapa |
| `sitemap.xml` | Vietnes karte Google Search Console |
| `robots.txt` | Meklētājprogrammu norādes |
| `CNAME` | Pielāgotais domēns (aiboostpro.lv) |
| `og-image.jpg` | Attēls, ko rāda, daloties ar saiti sociālajos tīklos (1200×630 px) |

## Tehniskais

- Statisks HTML/CSS/JS bez būvēšanas procesa — izmaiņas stājas spēkā 1–2 minūšu laikā pēc commit
- Fonti: Syne (virsraksti), DM Sans (teksts) — Google Fonts
- Analītika: Google Analytics 4
- Kontaktforma: Formspree
- Strukturētie dati: ProfessionalService, LocalBusiness, FAQPage (schema.org)

## Izmaiņu veikšana

1. Atver failu GitHub tīmekļa redaktorā
2. Veic izmaiņas
3. Commit tieši `main` zarā
4. Pēc 1–2 minūtēm pārbaudi lapu ar Ctrl+F5 (vai `?v=2` adreses beigās)

## DNS

Domēns reģistrēts nic.lv. A ieraksti norāda uz GitHub Pages IP adresēm, `www` — CNAME uz `aiboostprolv-tech.github.io.`

## Svarīgi

Šis repozitorijs ir **publisks**. Nekad neievieto šeit API atslēgas, paroles vai klientu datus — tie būtu redzami ikvienam un paliktu git vēsturē arī pēc izdzēšanas.
